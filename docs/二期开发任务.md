# JW Keyboard Designer 业务系统开发路线图

## 项目目标

在现有键帽设计器基础上，构建完整业务流程：

```
设计器
 ↓
保存设计
 ↓
提交订单
 ↓
管理员接单
 ↓
生产队列
 ↓
TV生产看板
```

最终实现：

- 用户设计并保存键帽方案
- 用户提交生产订单
- 管理员后台查看并接收订单
- 车间 TV 实时显示生产任务
- 后续支持支付、物流、通知等功能扩展

# 第一阶段：基础架构

目标：

建立数据库、ORM、认证体系。

预计：1~2天

## Task 1：Prisma

位置：

```
apps/api
```

安装：

```
pnpm add prisma @prisma/client
pnpm prisma init
```

创建：

```
apps/api/prisma/
```

结构：

```
prisma

├── schema.prisma
├── migrations
```

## Task 2：数据库连接

配置：

```
DATABASE_URL=postgresql://postgres:123456@localhost:5432/keyboard
```

验证：

```
pnpm prisma db pull
```

成功连接 PostgreSQL。

## Task 3：用户表

建立：

```
enum UserRole {
  USER
  ADMIN
}

model User {

  id String @id @default(cuid())

  email String @unique

  passwordHash String

  role UserRole @default(USER)

  createdAt DateTime @default(now())

  updatedAt DateTime @updatedAt
}
```

迁移：

```
pnpm prisma migrate dev
```

# 第三阶段：设计存储系统

目标：

把设计器数据保存到数据库。

预计：2~3天

## Task 7：Design表

```
model Design {

  id String @id @default(cuid())

  name String

  previewUrl String?

  data Json

  userId String

  createdAt DateTime @default(now())

  updatedAt DateTime @updatedAt

  user User @relation(fields:[userId], references:[id])
}
```

```
apps/api/src/modules/design
```

# 第四阶段：订单系统

目标：

实现用户下单。

预计：2~4天

## Task 10：Order表

```
enum OrderStatus {

  PENDING

  ACCEPTED

  PRODUCING

  COMPLETED

  SHIPPED
}

model Order {

  id String @id @default(cuid())

  userId String

  designId String

  quantity Int

  packageType String?

  remark String?

  status OrderStatus @default(PENDING)

  createdAt DateTime @default(now())

  updatedAt DateTime @updatedAt
}
```

## Task 11：Order Module

API：

### 创建订单

```
POST /orders
```

### 我的订单

```
GET /orders
```

### 订单详情

```
GET /orders/:id
```
