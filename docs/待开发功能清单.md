# 待开发功能清单（基于客户需求文档对照现有代码）

> 说明：本清单只列**尚未实现 / 半成品需要补完**的功能，用于评审与工期评估。
> 标记含义：
> - ❌ **未实现**：仓库中无对应能力，需从零开发。
> - ⚠️ **半成品**：已有基础，但达不到需求描述，需要补充/改造。
> - 已实现的功能不在本清单内（详见文末「已具备能力」一节）。

## 附：已具备能力（无需重复开发）

- **编辑器**：2D 键帽颜色定制（单键/批量/全局、取色器、Hex 输入）、内置字体 + TTF/OTF 自定义上传、字号/字距/行距、粗体斜体、本地图片 + SVG 上传、位置/尺寸/旋转、裁剪到键帽/顶面
- **导出/生产链路**：画板 SVG 导出、治具 JIG SVG 生成（服务端 opentype 转曲）
- **下单**：结算下单、支付、企业月结、团队批量下单
- **管理后台（现有）**：订单列表/详情、状态机流转、退款、生产看板（可全屏）、用户列表 + 改角色/账号类型、SSE 实时通知
